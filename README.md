# Interview-Preparation

A comprehensive, interactive Java Full-Stack Developer Interview Preparation platform built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Concepts Hub**: In-depth interview coverage of Core Java, Spring Boot, Microservices, Hibernate, React, TypeScript, SQL, Git, Testing, and HR.
- **Core Java, DSA & SQL Coding Preparation**:
  - **Core Java (55 Problems & Questions)**: Arrays (15), Strings (15), Collections Framework (15), Exception Handling (5), Multithreading (5).
  - **DSA & Coding (30 Curated Problems)**: High-frequency interview patterns across Arrays, Strings, Hashing, Two Pointers, Sliding Window, Searching & Sorting, Linked List, Stack & Queue, and Recursion.
  - **SQL Queries (43 Real-World Queries)**: SQL Basics, Keys & Constraints, Joins, Subqueries, GROUP BY & Aggregates, Common Interview Queries, Normalization, and Indexes.
- **Interactive Features**:
  - Instant in-place expandable code solutions
  - Syntax-highlighted code blocks with copy-to-clipboard
  - Learn Mode vs. Practice Mode
  - LocalStorage progress tracking
  - Live search and difficulty filters

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/MohanNerasala/Interview-Preparation.git

# Navigate to the project directory
cd Interview-Preparation

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
